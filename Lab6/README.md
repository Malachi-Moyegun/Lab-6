# HW 6 - Product Card Grid

A responsive streetwear store product grid built with HTML and CSS.

## Files
- `index.html` — website content and six product cards
- `style.css` — layout, hover effects, sale badges, and responsive styles

## How to view
Open `index.html` in a web browser.

## Responsive layout
- Desktop: 3 columns
- Tablet (900px or less): 2 columns
- Mobile (600px or less): 1 column

The Add to Cart buttons demonstrate hover styling; a functional cart is not required for this assignment.

## Submission
Upload the files to a GitHub repository and submit the repository URL to Canvas. If hosting via GitHub Pages, place the files at the repository root or configure the publishing source accordingly.
